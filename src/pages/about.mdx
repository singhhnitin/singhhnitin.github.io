## About the Project

This website documents my work as a Google Summer of Code 2026 contributor at the DBpedia Hindi Chapter.

The project focuses on Hindi relational triple extraction through fine-tuning small language models and developing a human-in-the-loop feedback interface.

## Project Objectives

- Improve Hindi relational triple extraction.
- Fine-tune lightweight language models.
- Build a human-in-the-loop feedback workflow.
- Convert reviewer corrections into training data.
- Improve structured knowledge extraction for Hindi.

## Weekly Updates

This blog serves as a development journal where I publish weekly updates covering:

- Experiments
- Model training
- Evaluation results
- Challenges
- Research findings
- Project progress
